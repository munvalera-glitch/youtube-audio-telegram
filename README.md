# Telegram-бот для скачивания аудио с YouTube

Простой и надежный Telegram-бот на Python для автоматической загрузки оригинальных аудиодорожек (в формате **M4A / Opus / WebM**) с YouTube-канала без скачивания видеопотока и без лишнего перекодирования.

Проект создан в рамках первого этапа автоматизации публикации прославления и проповедей воскресных служений в церковном Telegram-канале.

---

## 📋 Возможности

- **Поддержка форматов ссылок:** `youtube.com/watch`, `youtube.com/live`, `youtu.be`.
- **Проверка завершения трансляции:** скачивает только завершенные прямые эфиры и опубликованные видео.
- **Чистое аудио:** скачивает лучшую доступную аудиодорожку (приоритет отдается M4A / AAC, также поддерживается Opus/WebM) без загрузки видеопотока.
- **Исходное качество:** аудио не пережимается в MP3, сохраняется оригинальный битрейт и размер файла.
- **Безопасность и контроль доступа:** скачивание доступно только пользователям, чей Telegram ID указан в белом списке `ALLOWED_USER_IDS`.
- **Команда `/whoami`:** любой пользователь может узнать свой ID для добавления в белый список.
- **Асинхронность и неблокирующий режим:** длительное скачивание выполняется в фоновом потоке, бот продолжает отвечать на команды (`/status`, `/help`).
- **Подробный отчет:** после загрузки бот присылает название, длительность, формат, битрейт, размер, время и скорость загрузки, а также список глав (таймкодов), если они размечены на YouTube.
- **Автоматические повторные попытки:** до 3 попыток при временных сетевых ошибках.

## 🛠 Системные требования

- **ОС:** macOS, Linux или Windows.
- **Python:** 3.9+ (рекомендуется 3.10+).
- **FFmpeg:** (рекомендуется для универсальной работы с медиаконтейнерами).
  - На macOS через Homebrew:
    ```bash
    brew install ffmpeg
    ```
- **Node.js или Deno:** (для решения JavaScript-челленджей YouTube).
  - На вашем компьютере уже присутствует Node.js (`/opt/homebrew/bin/node`).
  - При необходимости Deno устанавливается командой:
    ```bash
    brew install deno
    ```

## 🚀 Пошаговая инструкция по настройке и запуску

### Шаг 1. Создание Telegram-бота через @BotFather

1. Откройте приложение Telegram и найдите официального бота **[@BotFather](https://t.me/BotFather)** (с синей галочкой).
2. Нажмите **Start** или отправьте команду `/start`.
3. Отправьте команду `/newbot`.
4. Введите видимое имя бота, например: `Church Audio Downloader`.
5. Введите юзернейм бота, который должен оканчиваться на `bot`, например: `my_church_audio_bot`.
6. После создания BotFather пришлет сообщение с токеном доступа к HTTP API вида:
   ```text
   7123456789:AAFlkJ...v8c92b
   ```
   *Сохраните этот токен в надежном месте и никому не передавайте.*

---

### Шаг 2. Настройка файла конфигурации `.env`

1. В папке проекта скопируйте файл-образец `.env.example` в `.env`:
   ```bash
   cp .env.example .env
   ```
2. Откройте файл `.env` в текстовом редакторе и укажите ваш токен:
   ```env
   TELEGRAM_BOT_TOKEN=7123456789:AAFlkJ...v8c92b
   ALLOWED_USER_IDS=
   DOWNLOAD_DIR=./downloads
   ```
   *(Параметр `ALLOWED_USER_IDS` можно пока оставить пустым, мы заполним его через команду `/whoami` на следующем шаге).*

---

### Шаг 3. Установка зависимостей и запуск

1. Активируйте виртуальное окружение:
   ```bash
   source .venv/bin/activate
   ```
   *(Если окружение еще не создано: `python3 -m venv .venv && source .venv/bin/activate`)*

2. Установите зависимости:
   ```bash
   pip install -r requirements.txt
   ```

3. Запустите автоматические тесты:
   ```bash
   pytest test_downloader.py -v
   ```

4. Запустите Telegram-бота:
   ```bash
   python bot.py
   ```

---

### Шаг 4. Настройка белого списка пользователей (`ALLOWED_USER_IDS`)

1. Откройте вашего созданного бота в Telegram и отправьте ему команду:
   ```text
   /whoami
   ```
2. Бот пришлет ваш цифровой Telegram ID (например, `123456789`).
3. Откройте файл `.env` на компьютере и добавьте ваш ID:
   ```env
   ALLOWED_USER_IDS=123456789
   ```
   *(Если пользователей несколько, укажите их через запятую: `123456789,987654321`)*
4. Перезапустите бота (`Ctrl+C` в терминале и снова `python bot.py`).

Теперь вы авторизованы и можете отправлять боту ссылки на YouTube!

1. Отправьте боту ссылку:
   ```text
   https://www.youtube.com/live/TdOcWQdNIRs
   ```

2. Бот ответит:

## 🍪 Обход ограничений YouTube (файлы cookies)

В последнее время YouTube активно внедряет защиту (SABR-потоки и требования GVS PO-токенов). При скачивании длинных многочасовых трансляций без авторизации YouTube может возвращать ошибку `HTTP Error 403: Forbidden`.

Бот автоматически поддерживает авторизацию через файл `cookies.txt`:
1. Установите расширение для браузера Chrome/Firefox (например, **"Get cookies.txt LOCALLY"**).
2. Зайдите на сайт [youtube.com](https://youtube.com) в браузере.
3. Экспортируйте файл cookies и сохраните его в папку проекта под именем `cookies.txt` (или укажите путь в переменной `COOKIES_FILE` в `.env`).
4. Бот автоматически подхватит его при каждом запросе.

## 🔄 Обновление `yt-dlp` без изменения кода бота

YouTube регулярно вносит изменения в защиту и протоколы воспроизведения. Чтобы обновить движок `yt-dlp` до самой последней версии без правок кода:

```bash
source .venv/bin/activate
pip install --upgrade yt-dlp
```
